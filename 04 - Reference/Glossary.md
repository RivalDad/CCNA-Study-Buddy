# CCNA Glossary — Days 1-17

[[00 - CCNA Home|← Home]]

| Term | Meaning |
|---|---|
| ARP | Address Resolution Protocol; maps local IPv4 addresses to MAC addresses |
| Broadcast domain | Devices that receive the same Layer-2 broadcast |
| BIA | Burned-In Address; factory MAC address terminology |
| CIDR | Classless Inter-Domain Routing; classless prefix-based addressing |
| Client | Device/process that accesses a service |
| Collision domain | Ethernet segment in which collisions can contend; each switch port forms its own |
| Default gateway | Router IP a host uses to reach remote networks |
| Default route | `0.0.0.0/0`, least-specific IPv4 route |
| Endpoint / end host | Device where application traffic begins or ends |
| Ethernet frame | Layer-2 PDU used by Ethernet |
| FCS | Frame Check Sequence; Ethernet CRC error-detection field |
| FLSM | Fixed Length Subnet Masking; all subnets same prefix size |
| Frame | Layer-2 PDU |
| Full duplex | Transmit and receive simultaneously |
| IHL | Internet Header Length; IPv4 header field measured in 32-bit words |
| MAC address | 48-bit Layer-2 address used by Ethernet |
| MTU | Maximum Transmission Unit |
| Native VLAN | VLAN whose frames are normally untagged on an 802.1Q trunk |
| Next hop | Next router/device in the routed path |
| OUI | Organizationally Unique Identifier; first 3 bytes of a MAC address allocation |
| Packet | Layer-3 PDU, e.g. IPv4 packet |
| PDU | Protocol Data Unit |
| ROAS | Router-on-a-Stick; inter-VLAN routing using router subinterfaces over a trunk |
| Router | Layer-3 device forwarding packets between networks |
| Server | Device/process providing a service |
| Static route | Manually configured route |
| Switch | Layer-2 device forwarding frames using MAC addresses |
| Trunk | Link carrying multiple VLANs, typically with 802.1Q tags |
| UTP | Unshielded Twisted Pair copper cabling |
| VLAN | Virtual LAN; separate Layer-2 broadcast domain |
| VLSM | Variable Length Subnet Masking; different subnet sizes within a parent block |
