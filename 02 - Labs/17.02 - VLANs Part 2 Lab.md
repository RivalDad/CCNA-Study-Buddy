# Lab 17.02 — VLANs Part 2 Lab

[[01 - Lessons/17 - VLANs Part 2|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Extend VLANs across switches with trunks and enable inter-VLAN routing using Router-on-a-Stick.

## Switch Uplink

```cisco
interface <uplink>
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30
```

## Router Subinterfaces

```cisco
interface g0/0/1
 no ip address
 no shutdown

interface g0/0/1.10
 encapsulation dot1q 10
 ip address <vlan10-gateway> <mask>
```

Repeat for each VLAN.

## Verify

```cisco
show interfaces trunk
show vlan brief
show ip interface brief
show ip route
```

Then ping:

```text
same VLAN across switches
local VLAN gateway
another VLAN gateway
host in another VLAN
```

## Troubleshooting Checklist

```text
Access port VLAN → trunk → allowed VLAN → dot1Q VLAN ID → gateway IP/mask
```
