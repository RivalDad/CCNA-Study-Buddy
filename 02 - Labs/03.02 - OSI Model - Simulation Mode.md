# Lab 03.02 — OSI Model - Simulation Mode

[[01 - Lessons/03 - TCP-IP and OSI Models|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Use Packet Tracer **Simulation Mode** to see encapsulation and protocol layering rather than treating a ping as one invisible event.

## What to Inspect

For each captured PDU/event:

1. Which protocol is active?
2. Which OSI/TCP-IP layer is it associated with?
3. What headers are added or removed?
4. Which addresses are visible at Layer 2 vs Layer 3?

Simulation mode may expose background/control traffic such as STP/OSPF depending on the topology, and higher-layer exchanges such as DHCP can exercise layers through the application stack.

## Packet Inspection Pattern

```text
Application data
↓
Transport PDU
↓
IP packet
↓
Ethernet frame
↓
Bits/link
```

> [!tip]
> Pause on each device and explain **why that device touches a particular layer**. A switch primarily changes the Layer-2 forwarding path; a router removes/rebuilds Layer 2 and makes a Layer-3 decision.
