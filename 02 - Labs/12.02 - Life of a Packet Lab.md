# Lab 12.02 — Life of a Packet Lab

[[01 - Lessons/12 - Life of a Packet|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Identify the source/destination MAC and IP addresses at each hop.

## Rule to Prove

```text
Source/Destination IP → remain end-to-end in this exercise
Source/Destination MAC → change at each routed hop
```

## Exercise Pattern

For every link, write:

| Link | Source MAC | Destination MAC | Source IP | Destination IP |
|---|---|---|---|---|
| PC-A → R1 | | | | |
| R1 → R2 | | | | |
| R2 → PC-B | | | | |

Then use Packet Tracer Simulation Mode to verify your table.

> [!tip]
> If you cannot name the destination MAC on a link, ask “Who is the **next Layer-2 neighbor**?” — not “Who owns the final destination IP?”
