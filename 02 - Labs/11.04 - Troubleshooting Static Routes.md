# Lab 11.04 — Troubleshooting Static Routes

[[01 - Lessons/11B - Static Routing|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Find deliberately incorrect configurations rather than simply rebuilding the topology.

## Common Fault Types in the Course Lab

- Wrong static-route next hop.
- Wrong exit interface.
- Incorrect interface IPv4 address.
- Missing/incorrect route causing one-way connectivity.

## Structured Troubleshooting

```text
1. Define exactly what can/cannot ping.
2. Check source IP/mask/gateway (`ipconfig` on PC).
3. Ping the local gateway.
4. On routers, `show ip route`.
5. Check directly connected route/interface IPs.
6. Walk the expected next hops.
7. Verify the reverse route.
8. Make one change; retest.
```

> [!danger]
> Do not add random routes until the ping works. First identify which routing-table decision is wrong.
