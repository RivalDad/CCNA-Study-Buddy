# Lab 09.02 — Configuring Interfaces

[[01 - Lessons/09 - Switch Interfaces|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Practice operational interface configuration and verification.

## Typical Tasks

```cisco
interface <interface>
 description ## to device ##
 speed <value>
 duplex <full|half|auto>
 no shutdown
```

For unused switch interfaces:

```cisco
interface range <range>
 shutdown
```

## Verify

```cisco
show interfaces status
show interfaces description
show interfaces
show ip interface brief
```

## Observe

- Speed/duplex negotiation vs manual configuration.
- Error counters.
- Interface state before and after shutdown/no shutdown.
