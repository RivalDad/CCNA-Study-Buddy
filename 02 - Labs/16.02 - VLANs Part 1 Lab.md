# Lab 16.02 — VLANs Part 1 Lab

[[01 - Lessons/16 - VLANs Part 1|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Create VLANs, place access ports into the correct VLANs, configure corresponding IP networks/gateways, and verify isolation/connectivity.

## Switch Pattern

```cisco
vlan 10
 name ADMIN
interface <pc-port>
 switchport mode access
 switchport access vlan 10
```

## Verify

```cisco
show vlan brief
```

## Lab Thinking

- A host port should appear in the intended VLAN.
- Hosts in the same VLAN/subnet should communicate at Layer 2.
- Hosts in different VLANs need a Layer-3 path.
- The configured default gateway must belong to the host's subnet.
