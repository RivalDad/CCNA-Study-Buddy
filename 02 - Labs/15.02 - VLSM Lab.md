# Lab 15.02 — VLSM Lab

[[01 - Lessons/15 - Subnetting Part 3 - VLSM|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Subnet a single `/24` into several differently sized networks using VLSM, then configure and route them.

## Method

```text
1. Sort host requirements largest → smallest.
2. Pick the smallest fitting prefix for each.
3. Allocate from the start of the parent range.
4. Record network/first/last/broadcast.
5. Address hosts/routers using the lab convention.
6. Configure static routes.
7. Verify end-to-end pings.
```

The course exercise uses `192.168.5.0/24` and multiple differently sized subnets, including a point-to-point link.
