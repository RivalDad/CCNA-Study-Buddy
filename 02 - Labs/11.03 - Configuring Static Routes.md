# Lab 11.03 — Configuring Static Routes

[[01 - Lessons/11B - Static Routing|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Build end-to-end connectivity using manual routes and verify every router's forwarding decision.

## Method

1. Confirm directly connected networks first.
2. Identify which remote destination networks are missing from each routing table.
3. Choose a reachable next hop or correct exit interface.
4. Add the static route.
5. Verify with `show ip route`.
6. Ping progressively farther destinations.

```cisco
ip route <network> <mask> <next-hop>
show ip route
ping <destination>
```

> [!tip]
> Draw the **return path** before declaring the forward route complete.
