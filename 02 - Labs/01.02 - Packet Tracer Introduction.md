# Lab 01.02 — Packet Tracer Introduction

[[01 - Lessons/01 - Network Devices|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Learn the Packet Tracer workspace before configuration complexity is added.

## Skills to Practice

- Identify routers, switches, PCs, servers, and interface labels.
- Place and connect devices.
- Choose an appropriate cable/port.
- Recognize **Realtime** vs **Simulation** mode.
- Save versions of a `.pkt` file as the lab evolves.

> [!tip] Lab habit
> Before changing configuration, verify the **device name, physical port, and cable**. A later troubleshooting lesson in our lab work reinforced that a correct config on the wrong physical interface is still wrong.

## Verification Checklist

- [ ] Every intended link is physically connected.
- [ ] Link indicators converge to an operational state.
- [ ] Device/interface labels match the diagram.
- [ ] Lab saved with a useful version name.
