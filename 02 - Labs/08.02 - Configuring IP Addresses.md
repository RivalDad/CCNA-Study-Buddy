# Lab 08.02 — Configuring IP Addresses

[[01 - Lessons/08 - IPv4 Addressing Part 2|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Configure router interface IPv4 addresses and host addressing, then prove Layer-3 reachability.

## Router Workflow

```cisco
enable
configure terminal
hostname R1
interface <interface>
 description <link purpose>
 ip address <ip> <mask>
 no shutdown
end
show ip interface brief
```

## Host Workflow

Configure:

```text
IP address
Subnet mask
Default gateway
```

Then test with `ping`.

## Troubleshooting Order

```text
1. Correct IP/mask?
2. Correct physical interface?
3. Router interface no shutdown?
4. Status/protocol up/up?
5. Host default gateway correct?
6. Ping local gateway before remote targets.
```
