# Lab 02.02 — Connecting Devices

[[01 - Lessons/02 - Interfaces and Cables|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Apply the copper/fiber and straight-through/crossover rules from [[01 - Lessons/02 - Interfaces and Cables|Day 2]].

## Core Decisions

```text
End host/router/firewall ↔ switch  → straight-through historically
Like device types                  → crossover historically
Auto MDI-X available               → interface can adapt automatically
Longer/optical requirement         → matching fiber + transceivers
```

## What to Observe

- Which interfaces become operational after cabling.
- Whether the chosen media/interface type is supported.
- Difference between copper and fiber links in Packet Tracer.

## Verification

```text
Physical link up
Correct devices/ports connected
Correct cable/media type
```
