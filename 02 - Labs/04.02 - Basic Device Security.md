# Lab 04.02 — Basic Device Security

[[01 - Lessons/04 - Cisco IOS CLI|← Parent lesson]] · [[03 - MOCs/Labs MOC|Labs MOC]] · [[00 - CCNA Home|CCNA Home]]


## Purpose

Practice the IOS mode hierarchy and basic device hardening commands introduced in Day 4.

## Configuration Pattern

```cisco
configure terminal
hostname R1
enable password <password>
service password-encryption
enable secret <secret>
end
copy running-config startup-config
```

## Verify

```cisco
show running-config
show startup-config
```

## Things to Notice

- Prompt changes when the hostname changes.
- `enable secret` is preferred over `enable password`.
- `service password-encryption` changes how supported plaintext passwords are stored/displayed, but course-era Type 7 is not strong cryptographic protection.
- Saving configuration is a separate action from entering configuration.
